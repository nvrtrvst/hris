# Audit 002 — Portal mobile (presensi PWA)

Tanggal: 2026-10-18. Mode: After. Scope: `resources/js/Layouts/MobileLayout.jsx`, `resources/js/Components/MobileUI.jsx`, `resources/js/Components/SlideToConfirm.jsx`, `resources/js/Pages/Mobile/**`.
Bukti kontras: dihitung WCAG 2.x (relatif luminans), bukan taksiran. Background acuan: putih `#ffffff`, page `#f4f7f5`, primary `#0F3D3E`.

## PASS (dengan evidence)

- R-32 keyboard: `SlideToConfirm.jsx:67-73` `role="slider"` + `tabIndex=0` + `Enter`, fallback terlihat "Ketuk langsung jika tidak bisa geser" (`:102-108`); `MobileLayout.jsx:89,163` `focus-visible:ring`.
- R-26 / C-2: tidak ada kontrol mati. Submit `Absen.jsx:764-771` dan `TetapPresensi.jsx:855-862` hidup, disabled ber-alasan.
- R-27: empty (`MobileUI.jsx:100` dipakai `TetapPresensi.jsx:867`), loading (`Jadwal.jsx:466,488`), error (`Dashboard.jsx:108`, `Absen.jsx:446`).
- R-01: gradient `from-black/90 via-black/40` (`Absen.jsx:593`, `TetapPresensi.jsx:737`) = keterbacaan teks di atas kamera; progress `Riwayat.jsx:205` = fill vs track (lanjutan catatan audit-001).
- R-15 / R-16: copy konkret tanpa buzzword ("Lakukan presensi keluar", `Dashboard.jsx:179`).
- R-17 / R-18 / R-36 / R-38: semua angka dari props nyata, tidak ada testimoni/klaim.
- R-11 radius kartu `rounded-2xl` = 1rem dan tombol `rounded-xl` = 0.75rem, sesuai `DESIGN.md`.
- R-37: `DESIGN.md` ada (arah brand teal `#0F3D3E` + accent `#C9A227`, Figtree).

## Findings

### HIGH (Hard Gate)

1. `[R-02]` Em dash di teks yang dilihat pengguna. Lokasi: `PulangCepat/Index.jsx:85,100,102`; `Koreksi/Index.jsx:82`; `Koreksi/Create.jsx:70`; `TetapPresensi.jsx:539,628,645,867`; `BuktiKegiatan.jsx:110` (atribut `title`); `Piket.jsx:237`.
2. `[R-02]` `'—'` sebagai placeholder nilai kosong: `Jadwal.jsx:19`, `Koreksi/Index.jsx:26`, `Koreksi/Create.jsx:23,57`, `PulangCepat/Index.jsx:33`, `Jadwal.jsx:271`.
3. `[R-25]` `text-slate-400`: 2.56:1 di putih, 2.38:1 di `#f4f7f5` (butuh 4.5). Dipakai untuk teks nyata di `MobileUI.jsx:107`, `Jadwal.jsx:168,185,271,466,488,507`, `Riwayat.jsx:207,219,324`, `Profile.jsx:22,173,175,178,182`, `Izin/Show.jsx:68,75,85,97`, `Koreksi/Index.jsx:80`, `Koreksi/Create.jsx:49,57`. Catatan: `slate-500` di page bg 4.41:1 juga gagal, jadi target `slate-600` (6.92 di `slate-100`, 7.58 di putih).
4. `[R-25]` `text-white/50` di primary = 4.22:1 (< 4.5). `Dashboard.jsx:141,163`.
5. `[R-25]` Warna teks semantik 600 di bawah ambang: `text-emerald-600` 3.77:1 (`Riwayat.jsx:281,364`; `Izin/Show.jsx:121,148`; `Profile.jsx:179`; `BuktiKegiatan.jsx:90`), `text-amber-600` 3.19:1 (`Riwayat.jsx:276,281,364`; `Izin/Show.jsx:177`; `BuktiKegiatan.jsx:131,141`). Naikkan ke `-700` (emerald-700 5.48, amber-700 5.02) khusus pemakaian teks; pemakaian ikon boleh tetap (ambang 3:1).
6. `[R-25]` Ikon `text-emerald-400` (#34d399) di putih = 1.9:1, di bawah 3:1 untuk elemen non-teks: `PulangCepat/Index.jsx:80`, `Koreksi/Create.jsx:54`, `Riwayat.jsx:319`.

### MEDIUM (Purpose-Gate)

7. `[R-29]` Warna di luar arah `DESIGN.md` (primary teal + accent amber, tanpa emerald/indigo/violet/lime tercatat): `indigo` di `Gaji/Index.jsx:31`, `Koreksi/Index.jsx:63`, `PulangCepat/Index.jsx:73`, `MobileUI.jsx:38` (alias indigo = emerald); palet 5 hue per kelas di `Jadwal.jsx:12-16` (violet/emerald/amber/rose/lime, violet 4.23:1 dan lime 3.09:1 di putih). Emerald dipakai sebagai warna solid sukses (`MobileUI.jsx:82`, `Absen.jsx:646`, `Riwayat.jsx:205`) tanpa tercatat sebagai warna resmi.
8. `[R-26 / C-3]` Kontrol debug ikut ke produksi: `MobileLayout.jsx:118-128` "Kirim Tes Notif" + kotak `testMsg` (`:145-149`) tampil untuk semua pegawai di menu akun.
9. `[R-04]` Dua sistem ikon: SVG heroicon inline di `MobileLayout.jsx:10-14,101,105,130` vs `lucide-react` di seluruh halaman lain.
10. `[R-06]` Drift dari spec `DESIGN.md` ("section label 0.75rem, tracking terbatas"): label uppercase `text-[9px]`/`text-[10px]` dengan `tracking-[0.16em]` di `MobileLayout.jsx:65`, `Jadwal.jsx:179`, `Dashboard.jsx:121`.

### LOW (Quality Locks)

11. `[R-08]` Panah: `ArrowRight` di setiap baris jadwal (`Jadwal.jsx:194`), `→` teks (`Jadwal.jsx:93,224,283`, `Koreksi/Index.jsx:77`), `Dashboard.jsx:180`, `Riwayat.jsx:324`. Baris jadwal memang membuka detail (`Jadwal.jsx:162`), jadi panah = affordance; alasan ditulis di sini dan di `DESIGN.md`. Teks `→` di rentang waktu = makna urutan, dipertahankan.
12. `[R-11]` `rounded-full` untuk chip konten (bukan status): `Riwayat.jsx:315,316`; FAB `rounded-2xl` (= radius kartu) padahal tombol = `DESIGN.md` 0.75rem: `MobileUI.jsx:55`; `rounded-lg` di overlay media (`Absen.jsx:641,676`, `TetapPresensi.jsx:782,812`) belum terdaftar di `DESIGN.md`.
13. `[R-09]` Kombinasi penuh di badge status (bg + border + uppercase tracking): `Dashboard.jsx:227,233,236`.
14. `[R-19]` `animate-pulse` tanpa purpose tertulis: `Jadwal.jsx:173`, `Dashboard.jsx:228`.
15. `[R-12]` Tiga resep shadow tanpa alasan tertulis: hero `Dashboard.jsx:117,185`, kartu `MobileUI.jsx:10`, FAB `MobileUI.jsx:55`.
16. `[R-21]` Tema dikunci light, alasannya (keterbacaan bawah sinar matahari) belum eksplisit di `DESIGN.md`.
17. `[R-37]` `DESIGN.md` belum mencantumkan baris dial.
