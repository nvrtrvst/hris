# Audit antislop 001 — Halaman Komponen Gaji (`/komponen-gaji`)

- Tanggal: 2026-10-21
- File: `resources/js/Pages/Payroll/Komponen.jsx`
- STANDAR AUDIT: antislop core + antislop-ui. Mode AFTER: tidak ada kode diubah sebelum user menyetujui nomor.
- Keluhan user: terlalu ramai/banyak badge, tabel terlalu padat, stat cards tidak perlu, poles umum ke arah simpel.
- **Sumber arah desain**: design system app yang sudah ada (token `input-field`, `card`, `btn-*`, warna `primary/emerald/rose/amber/sky/accent`). Audit berhenti di "kurangi noise tanpa ganti identitas app".
- Design Read: `app screen` untuk `admin HR yayasan`, bahasa `sistem admin yang sudah ada`, dial `ENERGY 1 / RHYTHM 1 / MOTION 1` (halaman kerja data, bukan landing).

## Yang sudah PASS (tidak disentuh)

- R-02: tidak ada em dash pada UI text.
- R-03: tap target 44px, overflow-x-auto, responsif.
- R-26/R-35: semua kontrol berkaitan (search, filter, edit, delete dengan modal konfirmasi, link matrix/pegawai) — fungsi dipertahankan utuh dalam sesuai permintaan user.
- R-27: loading + empty state ada dan informatif.
- R-32: aria/label/role untuk form field, table caption, sr-only sudah rapi.
- R-17/R-18/R-36/R-38: angka berasal dari data nyata (`stats` dihitung dari `komponens`); tidak ada testimoni/assertion palsu.

## Yang perlu diputuskan user

- Nomor berapa saja yang mau difix (contoh: "fix 1, 2, 4, 5, 9").
- Hal-hal yang akan berubah **hanya tampilan**; alur klik, data, dan properti tidak diubah sebesar apapun.
